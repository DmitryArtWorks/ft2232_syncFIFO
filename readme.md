# FTDI synchronous FIFO interface
Код в репозитории предназначен для извлечения данных с устройства посредством режима synchronous FIFO микросхем семества FT232h, FT2232H и так далее (на указанных ранее работоспособность была подтверждена). FT600/601 на данный момент не поддерживаются

### Содержимое репозитория

<ins>папка `ftSrc`</ins>: содержит все файлы, необходимые для работы с драйвером D2XX в 64-разрядных системах. Лично я использую оттуда только ftd2xx.h. Скорее всего. Насчет ftd2xx64.dll не уверен
<ins>`CMakeLists.txt`</inc>: файл CMake. Там прописан используемый компилятор, тип сборки и т.д.
<ins>`cutBin.m`</ins>: скрипт MATLAB, обрезающий начало бинарного файла. За всеми SDR замечена "корявость" приёма первых миллионов отсчетов, так что при визуальном анализе временнЫх диаграмм (я для этого использую pulseView) я начало обрезаю.
<ins>`ftd2xx.dll`</ins>: драйвер FTDI, который должен лежать рядом с исполняемым файлом для его корректной работы.
<ins>`main.c`</ins>: по названию, думаю, всё прекрасно понятно.
<ins>`readFTDI.m`</ins>: ещё один скрипт MATLAB, в котором реализовано моё видение метода проверки целостности передаваемых данных.
<ins>`receiveData.lnk`</ins>: ярлык, ссылающийся на исполняемый файл. Нужен для удобства запуска скомпилированного исполняемого файла от имени администратора. Админские права используются для запуска процесса исполняемого файла с приоритетом реального времени.

## Компиляция и запуск
Требуется компилятор GCC, установленный по гайду к VS Code(https://code.visualstudio.com/docs/cpp/config-mingw#_prerequisites), а также установленные в систему драйвера для FTDI.
- `git clone https://github.com/DmitryArtWorks/ft2232_syncFIFO.git`
- `cd ft2232_syncFIFO`
- `mkdir build`
- `cd build`
- `cmake .. -G "MinGW Makefiles"`
- `make`
- `.\receiveData.lnk`

Скорее всего этого будет достаточно для начала работы. На момент создания этого ридми код настроен на приём 1 млрд. байт данных и записи их в бинарный файл.
